## ✨ Features - Cloud - No PC Needed

### 🏥 Multi-Hospital System
- Each hospital gets unique CODE: `ROS001`, `KAB001`, `MUB001`, `ISN001`
- Patients: `ROS-0001`, `ROS-0002` vs `KAB-0001` - Separate, no mixing
- Logo: Upload per hospital or GLOBAL - Shows on all receipts

### 🔐 Secure Login - 3 Levels
1.  **Super Admin (You):** `marktechworld` / `markmk19` - Creates hospitals, deletes if not pay, extends license +30 days
2.  **Hospital Admin:** Creates users, sees all passwords, changes passwords, manages clinic
3.  **Staff:** `admin`, `doctor`, `lab`, `pharmacy`, `accountant` - Duty based - Can only change own password

### 👥 Patient Management - ID Based
- **Auto ID:** `ROS-0001` generates automatically - Cloud saved
- **Search by ID:** Type `ROS-0001` to see full history - Not just name
- **Full Address:** District * + Village * + Full Address - Ugandan style
- **Full History:** Doctor notes + Lab tests + Pharmacy + Bills - All linked to ID

### 🩺 Doctor Module
- View patient by ID: `ROS-0001`
- Diagnosis, treatment, notes - Saved to cloud
- History timeline per patient

### 🔬 Lab Module
- PENDING → COMPLETED workflow
- Lab tests linked to Patient ID
- Technician name + Result value

### 💊 Pharmacy Module
- Drug dispensing - PENDING → DISPENSED
- Linked to Patient ID - No errors

### 💰 Accounts Module
- **Bill by ID:** Enter `ROS-0001` → See all bills for that patient
- **Total Billed:** Dashboard shows total
- **Payments:** Receipt number `RCP-123456` auto
- **Balance:** Total billed - Paid

### 👥 Users Management - Admin Only
- Admin sees passwords: `lab1 / 1234` in table - Cloud
- Add new user: `lab1`, `lab2`, `doctor1`, `pharmacy1`
- Reset password to `1234`
- Change own password: Every staff can change own password (needs current password)
- Delete user

### 📅 License System - You Control
- Each hospital has expiry: 30 days from creation
- Dashboard shows: `25 days left` or `EXPIRED - Pay 50K to 0795769540`
- Super Admin buttons:
    - **Enter:** Login as that hospital
    - **Delete if not pay:** Stops hospital login - Shows "Hospital ID not found - Pay 0795769540"
    - **+30 days:** Extend when they pay monthly
